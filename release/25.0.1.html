25.0.1

5 分钟阅读 • 757 字 + 519 词
CodeForge v25.0.1 正式发布！这是一个重要的功能更新版本，我们在短短几天内就为用户带来了令人振奋的新特性。本次更新重点加强了多语言支持，升级了编辑器体验，并优化了整体性能表现。

📦 版本信息

  • 项目地址 ： https://github.com/devlive-community/codeforge
  • 官方网站 ： https://codeforge.devlive.org/
  • 版本号 ：v25.0.1
  • 发布日期 ：2025年8月18日

🌟 重大更新

🚀 多语言支持大幅扩展

我们在原有 Python 支持的基础上，新增了多种主流编程语言：
  • 🦀 Rust - 系统级编程语言，安全高效
  • 🐚 Shell - 脚本自动化的利器
  • ☕ Java - 企业级应用开发首选，配备专属图标
  • 🐹 Go - 现代化云原生开发语言
  • 🟢 Node.js - JavaScript 运行时环境，支持语法高亮

✨ 编辑器全面升级

  • 迁移至 CodeMirror ：采用业界领先的代码编辑器，提供更专业的编码体验
  • 编辑器配置 ：支持个性化编辑器设置，满足不同用户需求
  • 语法高亮优化 ：为新增语言提供完整的语法高亮支持
  • 配置统一 ：所有配置组件统一使用编辑器界面，操作更一致

🔧 核心功能增强

  • 自动更新机制 ：内置版本检查和更新功能，保持软件最新状态
  • 开发者工具 ：新增调试器和重新加载功能，便于问题排查
  • 加载优化 ：添加程序启动加载动画，提升用户体验
  • 日志系统优化 ：改进日志获取规则和处理方式

🎨 界面体验提升

  • Select 组件美化 ：支持图标显示，界面更加直观美观
  • Composition API 重构 ：Settings 和 App 组件采用 Composition API，代码更现代化
  • 插件配置优化 ：独立的插件配置管理，支持自定义模板

🛠️ 技术改进

架构优化

  • 模块化重构 ：继续推进组件模块化，提升代码维护性
  • 错误处理 ：修复多个核心问题，包括配置更新、命令执行等
  • 性能优化 ：优化代码执行流程，提升响应速度

开发体验

  • 自动化版本管理 ：添加自动化版本发布脚本
  • Issue 模板 ：完善问题反馈模板，提升问题处理效率
  • CDN 优化 ：演示视频使用 CDN 存储，加快访问速度

📚 文档更新

  • 下载文档 ：新增详细的下载和安装指南
  • 演示材料 ：更新演示图片和视频，展示最新功能

🐛 问题修复

本版本修复了多个重要问题：
  • 修复编辑器修改后配置未更新的问题
  • 修复错误代码引入导致的异常
  • 修复指定目录后执行命令位置不正确的问题
  • 修复默认插件未设置值的问题
  • 修复开发者模式异常问题
  • 修复无输出代码未反馈的问题
  • 修复删除日志未适配多级别格式的问题

🎯 下一步计划

我们将继续完善 CodeForge，后续版本将重点关注：
  • 更多编程语言支持
  • 更强大的插件生态
