CodeForge v25.0.4 正式发布！本次更新专注于 Apple 生态系统的完善和函数式编程能力的增强。我们新增了 4 种重要编程语言，特别是 Objective-C 家族的加入，让 CodeForge 成为 iOS/macOS 开发者验证代码的得力工具。

## ✨ 新增功能

### 新增语言支持

- **📱 Objective-C** - iOS/macOS 经典开发语言，Foundation 框架支持
- **⚡ Objective-C++** - Objective-C 与 C++ 混合编程，跨语言开发
- **🌙 Lua** - 轻量级脚本语言，游戏开发和嵌入式系统首选
- **🎩 Haskell** - 纯函数式编程语言，强类型系统

现在 CodeForge 支持 **29+** 种编程语言。
